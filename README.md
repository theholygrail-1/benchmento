# Benchmento

Browser tests for reaction time, click speed, spacebar speed, aim, typing, and working memory. Plus a few originals like [Split Test](https://benchmento.com/split-test/).

**Play:** [benchmento.com](https://benchmento.com/)

No account. Scores stay in local storage on the device you used. Nothing is uploaded.

## Tests

- [Reaction time](https://benchmento.com/reaction-time-test/)
- [CPS / click speed](https://benchmento.com/click-speed-test/)
- [Spacebar speed](https://benchmento.com/spacebar-test/)
- [Aim trainer](https://benchmento.com/aim-trainer/)
- [Sequence memory](https://benchmento.com/sequence-memory-test/)
- [Chimp test](https://benchmento.com/chimp-test/)
- [Split Test](https://benchmento.com/split-test/) — cut a shape in half by eye

## Why this repo exists

The site is the product. This repo is the public page for it: description, links, and a place people can star or open an issue.
